# Capturas de la aplicación

Capturas de pantalla de la ejecución de los casos de prueba de [03-plantilla-pruebas.md](../../03-plantilla-pruebas.md)
y de las incidencias de [04-registro-incidencias.md](../../04-registro-incidencias.md).

**Nombre de archivo:** `CP-XX_descripcion-corta.png` o `INC-00X_antes.png` / `INC-00X_despues.png`.

Ejemplos: `CP-05_tarea-creada.png`, `CP-12_sin-conexion.png`, `INC-001_antes.png`.

> No incluir contraseñas, tokens ni datos personales reales en las capturas. Usar solo los usuarios de prueba.
