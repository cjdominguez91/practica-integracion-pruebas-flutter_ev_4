# Pruebas y análisis

Salidas de los comandos de calidad, regeneradas antes de cada entrega:

```bash
flutter test -r expanded > docs/evidencias/pruebas-y-analisis/flutter-test.txt
flutter analyze > docs/evidencias/pruebas-y-analisis/flutter-analyze.txt
```

| Archivo | Caso |
|---|---|
| `flutter-test.txt` | CP-19 |
| `flutter-analyze.txt` | CP-20 |
| `flutter-analyze-inicial.txt` _(opcional)_ | Análisis inicial de la Fase 1 |
| `flutter-test-regresion-INC-00X.txt` _(opcional)_ | Re-prueba de una incidencia |
